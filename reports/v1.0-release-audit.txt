3. EXPLICITLY NARROWED SCOPE ITEMS (PARTIAL)
================================================================================
The following items are rated PARTIAL in accordance with architectural boundaries:

1. Process Attribution on Unprivileged Execution:
   - Status: PARTIAL (By Design)
   - Reason: Mapping local listening sockets to specific process names/PIDs requires
     administrative/root privileges on Windows and Linux.
   - Behavior: Unprivileged execution emits `WS-AUDIT-EXPOSURE-PERMISSION-LIMITED`
     without crashing.

2. macOS Kernel Routing Table Introspection:
   - Status: PARTIAL (By Design)
   - Reason: Native routing socket inspection on macOS requires BSD kernel headers.
   - Behavior: Falls back to system command parsers or returns empty route set safely.

3. Physical CI Hardware Runner Testing for Linux & macOS:
   - Status: PARTIAL (Deferred to Milestone 15)
   - Reason: Local development host is Windows 11 x86_64.
   - Behavior: Cross-compilation verified for `x86_64-linux`, `aarch64-linux`,
     `x86_64-macos`, and `aarch64-macos`. Automated physical runner testing is
     configured in `.github/workflows/ci.yml`.

4. Local Hash Tamper-Resistance:
   - Status: PARTIAL (By Design)
   - Reason: A local SHA-256 hash cannot protect against an attacker with write access
     to both report and manifest without external cryptographic PKI signing.
   - Behavior: Documented limitation; recommendations for external Sigstore/GPG signing.
