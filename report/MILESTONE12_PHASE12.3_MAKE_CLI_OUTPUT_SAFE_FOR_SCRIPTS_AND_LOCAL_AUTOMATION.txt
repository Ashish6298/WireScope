2. Implementation Summary:
   Hardened the WireScope CLI interface for headless script automation, continuous
   integration (CI/CD) pipelines, and local quality gates:
   - Non-Interactive Execution Guarantees:
     * Validated `--non-interactive` and `-y` flags across all CLI dispatch paths.
     * Enforced zero blocking prompts: WireScope never reads from stdin or blocks
       on interactive prompts in non-interactive mode.
   - Strict Scope Authorization & Safety Gate Invariant:
     * Non-interactive mode explicitly does NOT bypass authorization policies or
       broad assessment scope constraints.
     * Remote (non-loopback) targets evaluated without `--confirm-authorized`
       immediately fail safely with exit code 2 (`invalid_input`), leaving stdout
       empty and logging an actionable error to stderr.
     * When `--confirm-authorized` is provided, execution proceeds non-interactively
       without prompts.
   - Deterministic Exit Code Contract:
     * Code 0 (`success`): Clean execution, all policy checks passed, report valid.
     * Code 1 (`findings_or_violations`): Security findings (medium/high/critical)
       or defensive policy violations detected. Enables CI quality gate failure.
     * Code 2 (`invalid_input`): Malformed inputs, missing parameters, unknown
       profiles, unauthorized remote targets, unforced file overwrite attempts,
       or invalid report schemas.
     * Code 3 (`operational_failure`): Missing files, OS I/O failures, or operational
       execution crashes.
     * Code 4 (`cancelled`): Early termination due to deadline or operator signal.
   - Pristine Machine-Readable Stream Separation:
     * When `--format json` is requested, `stdout` strictly contains only pure,
       unpolluted JSON parseable by `jq`, `ConvertFrom-Json`, or language parsers.
     * Diagnostic logs, authorization warnings, and error messages route exclusively
       to `stderr`.
   - Automation Examples & Runnable Fixtures (`examples/automation/`):
     * `check_local_policy.sh` and `check_local_policy.ps1`: Automated offline policy
       evaluation with exit code inspection and JSON parsing.
     * `assess_authorized_target.sh` and `assess_authorized_target.ps1`: Schema validation
       and safe Markdown export from an authorized assessment report fixture.
     * `verify_safety_gate.sh` and `verify_safety_gate.ps1`: Verification that remote
       targets without `--confirm-authorized` fail safely with exit code 2.
     * `examples/assessment_report.json`: Golden valid assessment report fixture.
     * `examples/automation/README.md`: Quickstart automation guide.
   - Documentation & Architectural Specifications:
     * Authored ADR 0035 (`docs/decisions/0035-cli-automation-and-scripting-contracts.md`).
     * Authored comprehensive guide `docs/automation.md`.
     * Updated `README.md` marking Milestone 12 and Phase 12.3 as COMPLETED.
